# Difference between library and frameworks 
### Library 
Library is a collection of previous and code That can be used to perform specific task eg : axios
### framework
A framework is also a set of pre written code But its provide a structure for developing software application eg: express

# Express
A Node.js web application framework that helps us to make web applications
It is used for server side programming.
